A semantic toolbox for designing, validating, and understanding neuro-symbolic AI systems.

Why Tool4Boxology

Neuro-symbolic architectures deserve a shared, checkable language.

UML and ML-pipeline editors don't capture what a NeSy component is, or enforce whether it's valid. Boxology closes that gap.

Boxology (van Harmelen et al., 2023) is a typed notation for hybrid AI systems — elementary patterns of data, symbols, actors, processes, and models. Tool4Boxology lets you draw it, validate it against the T4B ontology, and turn it into a queryable RDF knowledge graph.

Getting started

Use the hosted online editor — no install needed. Or clone the GitHub repo and run npm run dev (or docker-compose up for the full pipeline).

Feature overview

Four pieces, one pipeline.

01

Visual editor

Drag data, symbol, actor, process, and model shapes onto the canvas and wire them into Input → Process → Output triples.

02

Semantic validation

Diagrams are checked against the T4B ontology, catching mismatches while they're easy to fix.

03

Knowledge graph export

An RML pipeline turns a validated diagram into a machine-readable RDF knowledge graph.

04

Interactive KG Viewer

Click any pattern in the graph for a live valid/invalid check — see it below.

Exploration layer

Every pattern in the knowledge graph documents and validates itself.

Click a pattern for its Type, a live VALID / INVALID status, and its inputs and outputs. Generate Documentation turns the whole graph into a shareable summary — or filter, search, and export the view as JSON or PNG.
